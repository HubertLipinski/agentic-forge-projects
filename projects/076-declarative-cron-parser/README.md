# Declarative Cron Parser

## Description

Declarative Cron Parser is a simple and powerful automation tool that reads cron-like schedules directly from comments in your source code (`.js`, `.py`, `.go`, etc.) and generates a standard crontab file.

This allows developers to keep scheduled tasks colocated with the scripts they execute, improving discoverability, version control, and maintainability. No more hunting for a separate crontab file to figure out what's running and when.

```javascript
// examples/sample-project/task1.js

// @cron: 0 5 * * * /usr/local/bin/node /path/to/your/project/examples/sample-project/task1.js --source=api
// @cron: 30 5 * * * /usr/local/bin/node /path/to/your/project/examples/sample-project/task1.js --source=db

// ... script logic ...
```

## Features

-   **Declarative Scheduling**: Define cron jobs as comments right next to your code.
-   **Multi-Language Support**: Parses comments from any file type (`#`, `//`, `/*`, `--`, `<!--`).
-   **Glob Support**: Easily scan your entire repository for jobs using glob patterns.
-   **Crontab Generation**: Creates a standard crontab file ready to be used with `crontab -`.
-   **Watch Mode**: Automatically regenerates the crontab file when source files change.
-   **Validation**: Built-in validation for cron expressions and file paths to prevent errors.
-   **Customization**: Add custom headers and environment variables (like `PATH` or `SHELL`) to your crontab.

## Installation

You can install the tool globally via npm to use it as a command-line utility.

```bash
npm install -g declarative-cron-parser
```

Alternatively, you can add it as a dev dependency to your project and run it via `npx` or an npm script.

```bash
npm install --save-dev declarative-cron-parser
```

## Usage

The tool is run from the command line, providing glob patterns to find your source files and an output path for the generated crontab.

### CLI

```
declarative-cron <patterns...> -o <output_file> [options]
```

**Arguments:**

-   `<patterns...>`: (Required) One or more glob patterns to find source files.
-   `-o, --output <path>`: (Required) Path to the output crontab file. Use `-` to print to stdout.

**Options:**

-   `-w, --watch`: Watch for file changes and regenerate automatically.
-   `-i, --ignore <pattern>`: Glob pattern for files/directories to ignore. Can be used multiple times.
-   `--env.<VAR>="<value>"`: Set an environment variable in the crontab (e.g., `--env.SHELL="/bin/bash"`).
-   `--header <string>`: A custom string to prepend to the crontab header.

### Programmatic API

The core functions are also exported for programmatic use in your own scripts.

```javascript
import { run, buildCrontab } from 'declarative-cron-parser';

// Example: Generate a crontab file in a build script
async function generateCrontab() {
  await run({
    patterns: ['src/**/*.js', 'scripts/**/*.py'],
    output: 'dist/crontab.txt',
    env: {
      'MAILTO': 'devops@example.com',
    },
  });
}
```

## Examples

### 1. Basic Generation

Scan all `.js` and `.py` files in the `tasks/` directory and generate a crontab file named `project.crontab`.

**Command:**

```bash
declarative-cron "tasks/**/*.js" "tasks/**/*.py" -o project.crontab
```

**`tasks/send-reports.js`:**

```javascript
// @cron: 0 9 * * 1-5 /usr/bin/node /app/tasks/send-reports.js
console.log('Sending daily reports...');
```

**`tasks/cleanup.py`:**

```python
# @cron: 0 2 * * 0 /usr/bin/python3 /app/tasks/cleanup.py --days=7
print("Cleaning up old files...")
```

**Generated `project.crontab`:**

```
# ============================================================================
# DO NOT EDIT THIS FILE DIRECTLY!
# This file is automatically generated by the "declarative-cron-parser" tool.
# Changes will be overwritten on the next run.
# To add or modify cron jobs, edit the @cron comments in your source files.
# Generated on: 2023-10-27T10:00:00.000Z
# ============================================================================

# Source: /app/tasks/send-reports.js:1
0 9 * * 1-5 /usr/bin/node /app/tasks/send-reports.js

# Source: /app/tasks/cleanup.py:2
0 2 * * 0 /usr/bin/python3 /app/tasks/cleanup.py --days=7

```

### 2. Watch Mode with Environment Variables

Scan all files under the `scripts/` directory, set a `SHELL` variable, and watch for changes.

**Command:**

```bash
declarative-cron "scripts/**" -o crontab.txt --env.SHELL="/bin/bash" --watch
```

**Initial Output:**

The tool will first generate `crontab.txt` and then print:

```
✨ Success! Processed 5 files and found 8 schedules.
Crontab written to crontab.txt in 45.12ms.

Watching for file changes in: scripts/**
Press Ctrl+C to exit.
Initial file scan complete. Watcher is now active.
```

Now, if you add or modify a `@cron` comment in any file within `scripts/`, the `crontab.txt` will be automatically and instantly updated.

### 3. Output to Stdout for Piping

Parse files and pipe the output directly to the `crontab` command to immediately install it.

**Command:**

```bash
declarative-cron "src/**/*.js" -o - | crontab -
```

This is extremely useful for deployment scripts and CI/CD pipelines.
