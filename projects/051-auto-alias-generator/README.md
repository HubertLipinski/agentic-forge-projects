# Auto Alias Generator

A smart CLI tool that scans your shell history to identify your most frequently used commands and suggests optimized, short aliases for them. It helps developers and power-users speed up their terminal workflow by creating memorable shortcuts for repetitive tasks.

![Auto Alias Demo](https://user-images.githubusercontent.com/12345/your-demo-image.gif)
*(Note: Add a demo GIF to your repository for better visualization)*

## Features

-   **Automatic Shell Detection**: Parses common shell history files (`.zsh_history`, `.bash_history`, `.fish_history`).
-   **Intelligent Analysis**: Analyzes command frequency and ranks them to find your most repetitive tasks.
-   **Smart Suggestions**: Generates short, intuitive, and non-conflicting alias suggestions (e.g., `git status` -> `gs`).
-   **Interactive Mode**: Review, edit, and select which aliases to generate using an interactive checklist.
-   **Ready-to-Use Output**: Prints alias definitions in a format ready to be pasted into your shell configuration file (`.bashrc`, `.zshrc`, etc.).
-   **Highly Configurable**: Customize scan depth, minimum command frequency, alias length, and more.
-   **Safe by Default**: Includes a built-in exclusion list to ignore common or potentially dangerous commands (`rm`, `sudo`, `ls`).

## Installation

You can install `auto-alias` globally via npm, which is the recommended approach.

```bash
npm install -g auto-alias
```

Alternatively, you can clone the repository and run the tool locally:

```bash
git clone https://github.com/your-username/auto-alias.git
cd auto-alias
npm install
npm link # To make the 'auto-alias' command available globally
```

## Usage

Simply run the command in your terminal. The tool will automatically find your shell history file, analyze it, and present you with a list of suggestions.

```bash
auto-alias
```

This will start the interactive prompt where you can select the aliases you want.

### Command-Line Options

You can customize the behavior using the following flags:

| Option                  | Alias | Description                                                  | Default |
| ----------------------- | ----- | ------------------------------------------------------------ | ------- |
| `--limit <number>`      | `-l`  | Number of recent history lines to scan.                      | `1000`  |
| `--min-frequency <num>` | `-f`  | Minimum times a command must appear to be suggested.         | `5`     |
| `--alias-length <num>`  | `-a`  | Preferred length for generated aliases.                      | `2`     |
| `--num-suggestions <n>` | `-n`  | Number of top alias suggestions to display.                  | `10`    |
| `--file-path <path>`    | `-p`  | Explicitly provide a path to a shell history file.           | `null`  |
| `--non-interactive`     |       | Run in non-interactive mode and print all suggestions.       | `false` |
| `--version`             | `-v`  | Display the version number.                                  |         |
| `--help`                | `-h`  | Display the help screen.                                     |         |

### Applying the Aliases

After you select the desired aliases, the tool will print them to the console.

1.  **Copy** the generated output.
2.  **Paste** it into your shell's configuration file (e.g., `~/.zshrc`, `~/.bashrc`, or `~/.config/fish/config.fish`).
3.  **Restart** your shell or source the configuration file to apply the changes:
    ```bash
    # For Zsh
    source ~/.zshrc

    # For Bash
    source ~/.bashrc
    ```

## Examples

### 1. Standard Interactive Scan

Run the tool with default settings. It will scan the last 1000 commands and suggest aliases for any command used at least 5 times.

**Command:**

```bash
auto-alias
```

**Expected Output (Interactive Prompt):**

```text
? Select the aliases you want to create (all are selected by default):
 (Use <space> to select, <a> to toggle all, <i> to invert selection)
❯◉ gs     ( 42x) -> git status
 ◉ ga     ( 31x) -> git add .
 ◉ gc     ( 28x) -> git commit -m
 ◉ gp     ( 19x) -> git push
 ◉ dcu    ( 15x) -> docker-compose up
 ◉ dcd    ( 12x) -> docker-compose down
 ◉ ni     (  9x) -> npm install
```

After selection, it will print the aliases to copy:

```text
┌─────────────────────┐
│  Your New Aliases   │
└─────────────────────┘

Copy the lines below and paste them into your ~/.zshrc file to apply.

# Generated by auto-alias on 2023-10-27T10:00:00.000Z
alias gs='git status'                      # git status
alias ga='git add .'                       # git add .
alias gc='git commit -m'                   # git commit -m
alias gp='git push'                        # git push
alias dcu='docker-compose up'              # docker-compose up
alias dcd='docker-compose down'            # docker-compose down
alias ni='npm install'                     # npm install
```

### 2. Deeper Scan for More Suggestions

Scan the last 5000 history entries and show up to 20 suggestions for commands that appear at least 10 times.

**Command:**

```bash
auto-alias --limit 5000 --min-frequency 10 --num-suggestions 20
```

This will provide a more comprehensive list of potential aliases based on a larger sample of your command history.

### 3. Non-Interactive Mode for Scripting

Run the tool non-interactively to get a raw list of all possible aliases. This is useful for scripting or if you prefer to manually filter the results yourself.

**Command:**

```bash
auto-alias --non-interactive
```

**Expected Output (Directly to Console):**

```text
🚀 Starting Auto Alias Generator...
🔍 Scanning history file: /Users/your-name/.zsh_history
Running in non-interactive mode. All suggestions will be printed.

┌─────────────────────┐
│  Your New Aliases   │
└─────────────────────┘

Copy the lines below and paste them into your ~/.zshrc file to apply.

# Generated by auto-alias on 2023-10-27T10:05:00.000Z
alias gs='git status'                      # git status
alias ga='git add .'                       # git add .
... (and so on)
```
